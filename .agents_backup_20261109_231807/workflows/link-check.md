# link-check (.agents/workflows/link-check.md)

## 概要
HTMLファイルやMarkdown内の内部リンク切れ、参照画像（`img src`）のパス欠落、存在しないアンカーリンクを自動検知してレポートする手順書です。
チャット欄で `/link-check` と入力して呼び出します。

## 実行手順
1. **対象ファイルの走査**:
   - リポジトリ内のすべての `.html` および主要 `.md` ファイルをリストアップする。
2. **パス・リンクの抽出と実在チェック**:
   - `href="..."` および `src="..."` のうち、相対パスで指定されているローカルファイルを検査する。
   - 参照先ファイルが実際のファイルシステム上に存在するか検証する。
   - 大文字・小文字の不一致やURLエンコードによる参照ミスがないか確認する。
3. **結果の報告**:
   - リンク切れが見つかった場合は対象行とパスを提示し、修正案を提示する。
   - すべて正常な場合は「全リンク検証完了: 破損なし」を報告する。
