# clean-tmp (.agents/workflows/clean-tmp.md)

## 概要
プロジェクト直下や作業領域に散らかった一時検証スクリプト（`tmp_*` 等）や検証差分ファイルを整理し、プロジェクトをクリーンな状態に保つ手順書です。
チャット欄で `/clean-tmp` と入力して呼び出します。

## 実行手順
1. **一時ファイルの検出**:
   - プロジェクト直下にある `tmp_*`, `test_*`, `diff_*.txt` 等の一時検証ファイルを検索する。
2. **退避ディレクトリの準備**:
   - プロジェクト内の `archive/tmp/` または `develop/tmp/` が存在するか確認し、なければ作成する。
3. **安全な移動（削除ではなく退避）**:
   - 後から参照できるよう、直ちに削除せず退避先へ移動（`Move-Item` / `mv`）する。
   - 移動対象のファイル一覧と移動先をユーザーに明示する。
4. **Git状態の確認**:
   - `git status` を実行し、プロジェクト直下がクリーンになったことを確認して完了を報告する。
