# Solar AM Notes ☀️ プロジェクト開発ルール

> [!IMPORTANT]
> 本リポジトリはメガソーラーのアセットマネジメント実務を学ぶための学習ノート静的Webサイト（GitHub Pages公開）です。
> リポジトリ: `https://github.com/nonoHP/solar-am.git` (ブランチ: `main`)

## 1. 文字コードの絶対ルール（UTF-8 厳守）
- **PowerShellのファイル書き換え禁止**: PowerShellの `Set-Content`, `Get-Content`, `>`, `>>` は UTF-16LE に変換され、日本語の文字化け（Mojibake）を引き起こすため絶対に使用しないこと。
- **編集ツールの限定**: ファイル編集は必ず AI編集ツール（`edit_file` 等）または Python (`open(..., encoding='utf-8')`) で行うこと。

## 2. ノート追加・修正とデータ整合性
- **ノート追加時の必須ステップ**:
  1. `notes/` 配下の既存ファイル（例: `om.html`）をテンプレートとして複製・編集する。
  2. `<body data-page="...">` のIDを新規ページ固有のものに変更する。
  3. **`assets/js/main.js` 冒頭の `PAGES` 配列に必ず1行追加すること**（メニューと前後リンクに自動反映されるため必須）。
  4. 見出しは `<section id="..."><h2>...</h2>...</section>` の構造を維持すること（目次が自動生成されるため）。
- **ニュース更新**:
  - `python scripts/fetch_news.py` により最新ニュースを取得・更新できる。

## 3. デザイン・UIコンポーネントの保全
- **ダークテーマUI**: `assets/css/style.css` の配色（ダークネイビー・ゴールド基調）を崩さないこと。
- **トピックフィルターと階層ナビ**: `assets/js/main.js` のトピックフィルター（現場・技術、発電性能、制度・蓄電池、金融・法務、実務リファレンス）および用語集検索機能を破壊しないこと。

## 4. 完全自動コマンド実行＆GitHub自動デプロイ絶対ルール
- **ユーザーへコマンド実行を絶対に求めない**: ビルド、Gitコミット、Gitプッシュ等のいかなるコマンド操作も、ユーザーに手動実行を依頼してはならない。すべてAI自身が自律的に全自動実行・完遂すること。
- **修正完了後の自動 GitHub デプロイ（Git Push）義務**: 作業完了後は自律的に `git add .` → `git commit` → `git push origin main` を一括で実行し、GitHub Pages への公開を完了させること。
- **エラー時の自律代替実行**: コマンドエラーが発生してもユーザーに尋ねず、代替スクリプト（Python `subprocess` 等）を作成して自律完遂すること。
