# backup-chat (.agents/workflows/backup-chat.md)

## 概要
現在のセッションで行われた指示、設計変更、重要な会話ログの要約をプロジェクト内のアーカイブ領域へ安全にバックアップ・保存する手順書です。
チャット欄で `/backup-chat` と入力して呼び出します。

## 実行手順
1. **保存先の確認**:
   - `archive/history/` ディレクトリが存在するか確認し、なければ作成する。
2. **会話・作業履歴のサマリー作成**:
   - 本セッションで実施した変更点、ユーザーからの特別な指示、解決した課題を Markdown 形式でまとめる。
   - ファイル名: `archive/history/chat_backup_YYYYMMDD_HHMM.md`
   - **文字コード**: 必ず UTF-8（BOMなし）で保存する。
3. **完了報告**:
   - 保存したファイルパスと主なバックアップ内容をユーザーに報告する。
