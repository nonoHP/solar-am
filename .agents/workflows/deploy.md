# deploy (.agents/workflows/deploy.md)

## 概要
変更内容を検証し、GitHub Pages（リモートリポジトリの `main` ブランチ）へ安全にビルド・コミット・プッシュする手順書です。
チャット欄で `/deploy` と入力して呼び出します。

## 事前確認
1. 文字コードが UTF-8（または指定エンコーディング）であることを確認する。
2. 作業用一時ファイル（`tmp_*` 等）がプロジェクト直下に残っていないか確認する。残っている場合は `/clean-tmp` を先に実行する。

## 実行手順
1. **変更差分の確認**:
   - `git status` で変更・追加されたファイルを確認する。
   - `git diff` で意図しない変更が含まれていないか確認する。
2. **動作・表示検証**:
   - HTML/CSS/JS またはスクリプトの構文エラーがないか確認する。
   - 相対パスやリソース（画像、リンク）が壊れていないか確認する。
3. **ステージングとコミット**:
   - `git add <対象ファイル>` （不要な一時ファイルを含めないよう注意）
   - コミットメッセージは変更内容が明確にわかる日本語で記述する。
   - 例: `git commit -m "feat: 〇〇機能の追加とレイアウト調整"`
4. **プッシュと公開確認**:
   - `git push origin main`
   - プッシュが正常に完了したことを確認し、GitHub Pages の公開URLをユーザーに報告する。
